# afqm-data-extract
Extracts data from AFQM.

- Install AFQM.
- Install [Undertale Mod Tool](https://github.com/UnderminersTeam/UndertaleModTool).
- Locate the <code>data.win</code> file and open it with ''Undertale Mod Tool''.
- Export all the scripts using ''Scripts'' > ''Resource Exporters'' > ''ExportAllCode.csx''. Create the folder wherever you would like.
- Grab the directory (ex: <code>C:/Users/LynnPetals/Documents/AFQM Code</code>) and modify the line of code in the Jupyter Notebook to match it.
