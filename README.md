# afqm-data-extract
Extracts data from AFQM.

- Have AFQM installed as well as [https://github.com/UnderminersTeam/UndertaleModTool Undertale Mod Tool].
- Locate the <code>data.win</code> file and open it with ''Undertale Mod Tool''.
- Export all the scripts using ''Scripts'' > ''Resource Exporters'' > ''ExportAllCode.csx''. Create the folder wherever you would like.
- Grab the directory (ex: <code>C:/Users/LynnPetals/Documents/AFQM Code</code>) and modify the line of code in the notebook to match it.
